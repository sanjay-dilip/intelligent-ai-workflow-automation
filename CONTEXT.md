# Project Context

## Problem
Business workflows (invoice processing, PO approval, support escalation,
onboarding, claims, etc.) silently accumulate SLA delays, manual-step
overhead, errors, and rework until operations teams discover the issue after
the fact. There is no proactive signal for which in-flight workflows need
attention.

## Users
Operations managers and analysts monitoring cross-department workflow health.

## Output
A Streamlit dashboard plus exportable CSV/JSON artifacts (predictions,
alerts, KPI summary, recommendations) that surface at-risk workflows and the
deterministic reasoning behind each flag.

## Scope
- Structured/tabular workflow data (synthetic, generated with a fixed seed).
- Random Forest classifier predicting workflow risk (low/medium/high).
- Deterministic rules engine for alerts and recommendations, independent of
  the ML model.
- KPI/SLA tracking engine.
- Streamlit dashboard with filtering and drill-down.

## Out of scope
- Multi-agent orchestration, LangGraph, RAG, vector databases.
- Any irreversible or externally-visible automated action (payments, account
  changes, terminations, external communications).
- Claims of production readiness or real-world model generalization.

## Data
Synthetic demonstration dataset generated by `scripts/generate_demo_data.py`
with a fixed random seed and probabilistic (not rule-exact) risk-label
assignment, to avoid trivial leakage between the label and the later rules
engine thresholds.

## Evaluation approach
Stratified train/test split, fixed seed. Metrics: accuracy, precision,
recall, F1 (macro/weighted), confusion matrix. Baseline comparison against
DummyClassifier and Logistic Regression to demonstrate the Random Forest adds
value over a trivial baseline. Synthetic-data performance is explicitly
documented as non-representative of real-world performance.

## Success criteria
All CLAUDE.md acceptance criteria: data validated, preprocessing reproducible,
model trainable/persistable, KPIs/alerts/recommendations deterministic and
tested, dashboard functional, outputs exportable, full test suite passing,
README commands verified to work as written.
